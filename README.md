# Self-Healing Observability Platform on Azure AKS

This project implements an enterprise-style self-healing observability pipeline using Azure Kubernetes Service, Terraform, Prometheus, Grafana, Alertmanager, Loki, and Python-based remediation automation.

## Core SRE Capabilities

- Golden Signals monitoring
- SLI/SLO and error budget dashboards
- Custom business metrics exporter
- Alertmanager webhook routing
- Automated remediation for stuck services and resource exhaustion
- Centralized logging with Loki
- Infrastructure as Code using Terraform
